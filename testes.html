ℹ Como usar

Escolhe o piloto, a categoria, a pista, os pneus e os mapas que vais testar — a tabela ajusta-se. Para cada pneu anota o desgaste numa volta (%, ex.: 3,5); para cada mapa anota o combustível gasto numa volta e o tempo. As colunas a verde calculam as voltas até o pneu acabar e as voltas por depósito cheio. Enter salta para o carro de baixo. Cada combinação piloto + categoria + pista guarda os seus próprios dados neste computador.
